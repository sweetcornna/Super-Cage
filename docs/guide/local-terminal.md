在 Super Cage 桌面应用里，环境中的终端也可以用这台电脑上的终端应用打开：在终端标签页或项目上选择“在本机终端中打开”（快捷键 ⌘⇧O）。窗口里运行的仍是环境中的同一个终端，Super Cage 网页终端、手机和本机窗口可以同时显示它。

## 用哪个应用打开

没有可选的：安装了 Ghostty 就用 Ghostty，没有安装就用 macOS 的系统终端，装上 Ghostty 之后下一次打开自动改用 Ghostty。设置的“本机终端”里，“在本机终端中打开”一栏只用一行字说明现在用哪一个。

用 Ghostty 打开时，第一次 macOS 会询问是否允许 Super Cage 控制 Ghostty（Super Cage 会先告诉你）；不允许的话窗口不会打开，可以之后在“系统设置 › 隐私与安全性 › 自动化”里允许。Ghostty 需要 1.3 或更新版本；打不开时 Super Cage 说明原因，并提供“复制命令”，在任何终端里运行同一条命令也能打开这个终端。用系统终端打开不需要任何权限。

这一栏下面“图片与剪贴板”有两个开关，只保存在这台电脑上，不会同步到环境或其他设备；已经打开的窗口和 ssh 连接在下次打开时使用新的选择：

- **上传拖入的图片**：把 PNG、JPEG、WebP 或 GIF 图片拖入窗口，或粘贴的内容只有图片文件的完整路径时，图片上传到环境，粘贴环境中的路径，与网页终端一致。其他文件和输入的文字原样发送。上传失败时窗口响铃，不会把这台电脑的路径发给环境。从你自己的终端 ssh 连进来时不上传，按文字粘贴。
- **允许环境写入剪贴板**：环境中的程序（例如 neovim、tmux）复制的内容写入这台电脑的剪贴板，ssh 连进来的终端也按这个开关。环境始终无法读取这台电脑的剪贴板。

Super Cage 锁定时，以及无法确认环境是否已解锁时（例如环境尚未启动或仍在连接），既不能打开窗口，也不能修改这些设置；解锁或等环境就绪后再试。本机终端只能在桌面窗口中由你操作，Agent 和手机都不能打开本机应用。

## 从你自己的终端连进来

同一页的“从你自己的终端连进来”开启后，在任何终端里用 `ssh <主机名>` 或 `cage ssh <环境>` 打开的会话（`ssh`、`ssh -t`）就是一个 Super Cage 终端，和本机终端应用的窗口一样：环境的输出经过下面的过滤器，离开时同样复原窗口，也按下面的规则共用终端。剪贴板写入只在你正在使用那个窗口时转发：终端应用报告焦点时以焦点为准，不报告时只在你最后一次按键或点击后的 3 秒内。拖入的图片不上传；回滚缓冲的清除照常放行，没有 `--keep-scrollback` 这样的选项。默认环境还列出 `cage attach`，在任何终端里新开一个这个环境的终端。不带终端的命令、scp、sftp 和 rsync 不经过过滤器，原样传送环境的字节。

也可以在你自己的终端里运行 `cage entry on` 开启：它在这个终端里问你一次 [y/N]，通过管道或脚本运行时不会开启。这个问题防的是脚本和误操作，不是安全边界：以你的账户运行的程序（例如这台电脑上能执行命令的 Agent）可以像你一样回答它。

## 多个窗口共用一个终端

每个窗口有自己的大小，但一个终端只有一个尺寸。规则与网页终端相同：

- 最后输入的窗口决定终端尺寸。还没有人输入，或者上次输入的窗口已经关闭时，改变窗口大小会立即生效。
- 程序询问光标位置、终端类型、颜色等信息时，只有决定尺寸的窗口的自动回答送达程序，问题只回答一次。
- 鼠标在窗口上移动（未按键）不算输入：它只从决定尺寸的窗口送达程序（决定尺寸的窗口已经关闭时照常送达），不会改变由谁决定尺寸；点击和拖动算作输入。

## 过滤器会改变什么

环境中的程序写到本机窗口的内容先经过过滤器。它只放行网页终端也会执行的控制序列，其余丢弃，因此有些效果与直接在本机运行不同：

- 剪贴板读取请求一律丢弃；写入只在开关打开、且你正在使用这个窗口时转发。
- 清除回滚缓冲（`CSI 3 J`）照常放行，与通过 SSH 使用时一致：Claude Code 等基于 Ink 的程序每次整屏重绘都会清除回滚缓冲，否则窗口的回滚里会堆积一份份旧画面。手动运行 `cage attach` 时加上 `--keep-scrollback`，程序就不能清除这个窗口的回滚缓冲（设置里没有这个选项）。
- 完整重置（`ESC c`，`reset` 和 `tput reset` 会发送）改为软重置、清屏、清除回滚缓冲（使用 `--keep-scrollback` 时保留）并把光标移到左上角：窗口照样恢复可用，终端应用自己的窗口设置（例如配色方案）保留。
- 数字参数大于 65535 的控制序列被丢弃，例如重复字符、插入字符和制表跳转，避免一条很短的序列让终端应用长时间运算。
- 颜色查询只放行能识别回答的形式：带多个字段的前景、背景、光标颜色查询被丢弃，前景、背景、光标颜色的恢复请求只放行不带参数的形式。
- 图片协议（Sixel、kitty 图形、iTerm2 内联图片）、未知或不完整的序列被丢弃；窗口标题和通知文字最多 256 个字符。
- 重新连接时回放的历史只用于显示：不会再次回答查询、写剪贴板、发通知或响铃。

## 关闭窗口与恢复

终端结束或你断开连接时，窗口立即关闭。离开之前，Super Cage 把窗口恢复成打开前的样子：关闭鼠标与粘贴模式、退出备用屏幕、恢复标题，并且只撤销程序改动过的内容，例如调色板、光标样式与闪烁、制表位、未结束的超链接、进度条和命令运行状态。

连接意外结束时，窗口先完整重置，再保留 Super Cage 的提示，显示“按任意键关闭”。

## 已知限制

- 环境中的程序对这个窗口能做的与通过 SSH 时相当：清屏并清除回滚缓冲、设置窗口标题、发通知，以及在窗口关闭前改变颜色和光标样式；它不能读取这台电脑的剪贴板或窗口里的文字，不能使用终端应用的远程控制和图片协议，窗口关闭时它改过的设置也会被撤销。
- 连接意外结束时，如果你在提示出现前继续打字，这个按键会被“按任意键关闭”读走，窗口随即关闭，来不及看到提示。
- 程序刚发出查询后的约 5 秒内，形状与回答相同的按键（例如 xterm 编码下的 Shift+F3，与光标位置回答相同）可能被当作回答：它不会让这个窗口取得终端尺寸，这个窗口不决定尺寸时也不会送达程序。
- 程序在一秒内发出超过 65535 次同类查询时，此后约 5 秒内这一类的回答都被当作回答。
- 按 Esc 后停顿片刻（超过约 25 毫秒）再输入 `]`、`P` 或 `[`，之后的输入在控制键（例如回车）或累计 128 个字节之前不算作你在使用这个窗口（照常送达程序）；终端应用不报告焦点时，这期间程序写剪贴板会被丢弃。
- 旧版手机应用一次积攒的输入超过 8000 个字符时（例如程序接连发出大量查询），可能把一条自动回答拆成两次发送，后一半会被当作按键：它会让手机窗口决定终端尺寸，并作为输入送达程序。更新手机应用后不再出现。
