## 打开网页与浏览器设置

点击侧栏“浏览器”，用地址栏访问网站，顶部加号新建页面。`claude.ai` 入口直接打开 Claude 官网。`localhost` 属于当前 Super Cage 客机，预览服务需从 Super Cage 终端启动。

**macOS 客机**会在工作台内显示 Google Chrome 的完整窗口。用 Chrome 自带的地址栏、标签页和菜单浏览、收藏或登录网站。更新环境组件后，Chrome 继续使用客机内原有的浏览器资料。以前保存在 Super Cage 的网页可从窗口上方的“收藏夹”打开。要使用 Super Cage 保险箱里已有的密码，在设置里打开密码保险箱，验证后复制到 Chrome。通过 Claude Code 发起账号授权时，会另外打开临时窗口，授权完成或取消后关闭。Claude Desktop 如果调用系统打开外部登录链接，使用的是虚拟 Mac 设置的默认浏览器。

macOS 客机进行完整联网检测时，Chrome 会临时打开检测页，实际读取页面的语言、时区和网络出口。日常使用可以关闭检测页。后台核对浏览器进程和资料设置。如果 Chrome 重启或设置变化，请按提示重新检测。

以下操作适用于使用 Super Cage 地址栏的客机。地址栏右侧的浏览器菜单提供设置、无痕和网站数据等操作。浏览器设置页可搜索“新标签页、外观、隐私与网站数据、扩展、关于浏览器”。新标签默认地址影响之后的新建标签；横排或竖排标签布局立即生效，保存在当前客户端。

关闭浏览器视图只返回原工作区，页面和登录继续保留。需结束无痕会话时，关闭全部无痕标签或停止环境。

网页复制同步保留网站原有的剪贴板接口，不向网页主执行环境添加产品标记，也不会为此授予网站额外的剪贴板读取权限。自动同步需要 Chromium 144 或更新版本；旧浏览器仍可正常浏览，需要自动同步时请更新环境工具中的浏览器。

Linux 环境在最后一个浏览器查看窗口离开后，将浏览器窗口最小化，让后台网页采用 Chromium 的节流机制。返回浏览器时恢复原窗口和未保存的输入。多个工作台同时查看时，仍在查看的窗口继续显示。手机浏览器拥有独立会话。

Linux 环境的浏览器和 Claude Desktop 画面按使用情况调整刷新率。操作键盘、鼠标或调整窗口时保持 60 Hz；停止操作约 3 秒后降到 30 Hz，约 3 分钟无操作后降到 20 Hz，再次操作时立即恢复。分辨率、字号和清晰度保持不变，网页动画与视频在无人操作时按较低帧率播放。此功能随环境组件更新启用，需要环境中的 `python3-xlib`：已安装 Claude Desktop 的环境直接生效，只使用浏览器的旧环境在下次更新环境工具后生效。

Linux 环境的浏览器和 Claude Desktop 按显示它的屏幕渲染。2 倍的高分屏上，画面的每个像素对应一个屏幕像素；100% 缩放的普通屏幕只渲染四分之一的像素，文字同样逐像素清晰。把窗口移到另一块屏幕或更改系统缩放后，画面随即按新的密度重绘，字号和可见内容保持不变。高于 2 倍的屏幕按 2 倍渲染。

新配置默认开启“设置 → 通用 → 优先流畅”：高分屏上按屏幕像素的四分之三渲染，2 倍屏的像素量减少约 44%；普通屏幕已是最少像素，不再降低。需要更清晰的细节时可关闭，设置在下次启动环境时生效。已有配置沿用原画质。

按屏幕渲染随环境组件更新启用，需要环境中的 `xsettingsd`：已安装 Claude Desktop 的环境直接生效，只使用浏览器的旧环境在下次更新环境工具后生效。在此之前以及 Windows 客机上，画面继续使用固定的 1.5 倍或 2 倍渲染。

Linux 环境的浏览器按触控板滑动的实际距离滚动：网页跟随手指移动，停手即停，不再按固定步长追赶和滑过头。带刻度的鼠标滚轮保留逐格滚动和网页自带的平滑动画；macOS 已经把滚轮刻度换算成距离，因此同样按距离滚动。指针位于下拉列表或菜单上、使用分屏或打开了开发者工具时，以及按住 Ctrl、Shift 等修饰键滚动时，继续使用原有的逐格方式。此行为随环境组件更新启用，旧组件保持逐格滚动。

macOS 和 Windows 客机的浏览器按滚轮或触控板的实际距离滚动。操作时画面最高 60 Hz，停止操作约 1 秒后回到 30 Hz，静止时进一步放慢取帧。此行为在客机组件更新后生效，旧组件继续按固定步长滚动。

地址栏右侧的下载按钮在右上角展开文件列表，可查看下载进度、另存为、打开文件或在文件夹中显示；保存失败时可重试。长列表在面板内滚动，点击外部或按 Esc 收起。

浏览器设置的“隐私与网站数据”集中了清除浏览数据、网站数据、浏览记录、保持登录的网站、自动清理和重置浏览器，见下文“清除浏览数据与网站数据”。“网站权限”打开 Chromium 对应页面；摄像头、麦克风等权限应结合环境实际设备能力判断。“关于浏览器”中的“搜索引擎”和“下载设置”可以打开更多原生浏览器配置；网页显示这些选项不代表 Super Cage 已接通所有设备能力。

## 收藏与标签管理

地址栏星标或 Mac 的 `⌘D` 可收藏当前页，修改名称并选择或新建收藏夹。收藏夹按钮或 `⌘⇧O` 打开管理，可搜索、打开、改名和移动收藏。Windows/Linux 对应使用 Ctrl。

删除收藏夹会将网页移至“未分类”。收藏属于当前 Super Cage 配置，所有项目共用，不随切换项目消失。

标签右键或 Shift+F10 可打开操作菜单，拖动改变顺序。列表较多时可搜索已打开网页；置顶标签在自己的分组内排序。

## 使用无痕会话

在菜单选“新建无痕标签”，或按 Mac 的 `⌘⇧N`、Windows/Linux 的 `Ctrl+Shift+N`。无痕标签和地址栏会明确标记。无痕页面的加号继续新建无痕标签，需要普通页时从菜单选择。

普通和无痕会话的 Cookie、登录与网站存储分开；同一批无痕标签共用临时会话。关闭最后一个无痕页会清理会话，重启不会恢复这些标签。无痕不会提示保存密码；主动保存的收藏和下载仍保留。

无痕会话继续使用相同代理出口，网站和代理服务仍能观察请求。隐藏窗口不会结束后台无痕进程。

## 清除浏览数据与网站数据

从浏览器菜单或浏览器设置的“隐私与网站数据”选“清除浏览数据…”，或按 Mac 的 `⌘⇧⌫`、Windows/Linux 的 `Ctrl+Shift+Delete`。选择时间范围（最近一小时、过去 24 小时、过去 7 天、过去 4 周、全部时间）和要清除的内容，每项旁边显示现有的数量或大小：

- **浏览记录**：访问过的网址和标题。
- **Cookie 和网站数据**：Cookie、localStorage、IndexedDB、缓存存储和 Service Worker。大多数网站会退出登录。
- **缓存的图片和文件**：网页再次打开时重新下载。
- **下载记录**：下载面板和 Chromium 中的记录；已下载的文件保留。

确认后显示清除了什么、释放了多少空间；失去登录状态的网页会自动重新加载。所选的时间范围和内容会记住，下次打开沿用。网站权限不在这里清除，对话框提供“查看网站权限”；已保存的密码属于 Super Cage 密码保险箱，在设置中管理。

在无痕标签中打开时可切换到“无痕会话”，按整个会话清除无痕网站数据和缓存，普通会话不受影响；无痕会话没有浏览记录。

### 保持登录的网站

在“隐私与网站数据”的“保持登录的网站”中添加域名（可直接粘贴网址），或从打开的网页一键添加，也可在地址栏左侧的网站按钮里打开“保持登录”。一个域名包含它的子域名，例如 github.com 也保留 gist.github.com。清除浏览数据时默认跳过这些网站和 Super Cage 内置页面（文件编辑器、Claude Science、浏览器组件），取消勾选“跳过…”才会一并清除。

本机地址的 Cookie 不区分端口：保护文件编辑器和 Claude Science 时，127.0.0.1 和 localhost 上其他预览服务的 Cookie 也会保留，它们的网站存储仍会清除。清除了内置页面的登录后，文件编辑器用浏览器菜单的“恢复编辑器”重新进入。

### 网站数据与 Cookie

“隐私与网站数据”→“网站数据”按网站列出 Cookie 数量和占用空间，可按占用空间、最近访问或名称排序，搜索网站，勾选多个网站后一起清除。点开一个网站可看到各地址的存储和全部 Cookie：查看值、删除单条（含分区 Cookie）或“清除此网站数据”。普通会话和无痕会话分别列出。

浏览器菜单的“管理 Cookie”和地址栏左侧的网站按钮直接打开当前网站的数据；网站按钮还可一键清除此网站的数据。

### 浏览记录

“隐私与网站数据”→“浏览记录”按日期列出访问过的网页，可搜索标题或网址，删除单条、删除某个网站的全部记录、删除一整天，或用“按时间清除…”。点击记录在新标签中打开。

### 自动清理与磁盘缓存

“自动清理”默认关闭。打开后可选择每次停止环境时清除，或每 1、7、30 天在下一次启动或停止环境时清除，并选择清除的内容；始终跳过保持登录的网站。重启环境不触发“停止时”清理。

浏览器的磁盘缓存不超过 256 MB，也不超过 Chromium 按剩余空间自行选择的大小和剩余空间的 5%。

### 重置浏览器

浏览器资料损坏、网页反复出错时，在“隐私与网站数据”底部选“重置浏览器…”。浏览器以全新的资料重新启动：所有网站的登录、Cookie、网站存储、浏览记录、缓存、网站权限、在 Chromium 扩展页安装的扩展和各扩展的设置都会清除。收藏夹、密码保险箱、通过 Super Cage 导入的扩展、新标签页地址、保持登录名单、自动清理设置和已下载的文件保留。账号授权页面打开时不能重置。

以上功能需要 Linux 环境和更新后的环境组件。macOS、Windows 客机和旧组件继续使用“管理 Cookie”面板和 Chromium 的“清除浏览数据”页面：可查看当前网站或所有网站的 Cookie、查看值、删单条、清空当前网站或当前会话的全部 Cookie；**搜索条件不会缩小清空范围**，清空普通会话全部 Cookie 也会清除文件编辑器认证。

## 安装或导入扩展

在浏览器设置的“扩展”中导入 Manifest V3 ZIP，单包上限 32 MB。安装前阅读界面列出的权限，再确认。仅安装可信来源，扩展可能读取它获准访问的网页内容。

桌面版可从本机 Edge、Chrome、Brave 或 Chromium 复制扩展及启停状态。导入不会复制浏览器账户、Cookie 或扩展自身的登录数据，部分标识变化的扩展需要重新配置。扩展在 Super Cage 浏览器中运行，本机浏览器的操作环境与网络不会因此迁移。

旧环境缺少入口或安装组件报错时，先更新应用与环境组件，再重新打开浏览器。

## 保存网站密码

网页登录完成后，在工具区选择“保存密码”或“更新密码”。再次访问时展开“密码”，选账号填入，最后由你提交登录。

“设置 → 密码保险箱”支持搜索、手动添加、修改、删除和恢复网站提示。查看或复制密码需再次输入 Super Cage 密码。支持范围与备份要求见[设置参考](settings.md#密码保险箱)。
